# Data

Raw and merged data files are **not committed** to this repo (the merged
CSV alone is ~154 MB; GitHub blocks files over 100 MB).

## How to get it

Run `scripts/sepsis_data_explore.py` from the repo root. It will:
1. Download the PhysioNet/CinC 2019 training data (Hospital A + B) via AWS S3
2. Merge all per-patient files into one DataFrame
3. Save `sepsis_merged.csv` into this `data/` folder
4. Print EDA stats (patient counts, class imbalance, missingness)

Source: PhysioNet/Computing in Cardiology Challenge 2019
https://physionet.org/content/challenge-2019/1.0.0/

## Files this folder will contain locally (gitignored)

- `sepsis_merged.csv` — full merged dataset
- `repA_train.csv`, `repA_val.csv`, `repA_test.csv` — patient-level split,
  Representation A (generated by `scripts/step1_split_and_baseline.py`)
